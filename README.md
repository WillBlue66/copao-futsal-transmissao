# Copão de Futsal - Landing Page

Landing page comercial em Vite + React + Tailwind CSS para apresentar pacotes de transmissão ao vivo do Copão de Futsal.

## Scripts

```bash
npm run dev
npm run build
npm run deploy
```

## GitHub Pages

O projeto está configurado com `base: '/copao-futsal-transmissao/'` em `vite.config.js` e com deploy via `gh-pages -d dist`.
